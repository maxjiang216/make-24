    how it works
    • Solvable? covers all 1820 sets (1362 solvable, 458 not): decide whether the set can make 24. Solve covers the 1362 solvable sets: find a solution.
    • Press any key (or tap) to turn the cards over; the timer starts then.
    • Solvable?: answer with → (solvable) or ← (unsolvable). It's checked for you, and any key deals the next set.
    • Solve: press any key when you have a solution. That stops the timer and shows every solution, so typing time doesn't count. Grade yourself with → (right) or ← (wrong).
    • There's no daily schedule: keep going as long as you like. The next set is the one you're weakest on, by recent accuracy and then by recent time. A set you just saw sits out for a while: a few turns after a miss, longer the more times in a row you get it right fast.
    • filter narrows the deck to sets that are easy to pick out: which ranks may appear, how many face cards (J Q K), and for Solve, the number of solutions (distinct, or a range of total written forms, where 4*6 and 6*4 count separately) and the strategy. Strategy can match the set's one canonical strategy, or any strategy one of its solutions uses. Your progress is kept for every set either way.
    • When every set that's available is one you currently get right and fast, a new set comes in, in the order you pick.
    • Progress is saved in this browser. Use export / import under ⋯ to back it up or move it to another device.
